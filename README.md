## Sobre o Projeto

Site desenvolvido como projeto escolar pela **Turma 201 do Colégio Murialdo** em homenagem a **José Lutzenberger**, ambientalista gaúcho, fundador da AGAPAN e vencedor do Right Livelihood Award (Prêmio Nobel Alternativo).

O site apresenta sua biografia, conquistas, legado filosófico e artigos produzidos pelos alunos.

## Acesse o Site

## Tecnologias Utilizadas

| Tecnologia | Uso |
|------------|-----|
| **HTML5** | Estrutura semântica |
| **CSS3** | Estilização, variáveis, responsividade |
| **JavaScript (Vanilla)** | Lógica e interações |
| **GSAP + ScrollTrigger** | Animações fluidas ao scroll |
| **Lenis** | Smooth scroll suave |
| **SplitType** | Animação de texto por caracteres |

---

## Funcionalidades

- Animações suaves de entrada (hero, cards, timeline)
- Scroll reveal nas seções
- Efeito 3D tilt nos cards ao passar o mouse
- Partículas sutis no fundo do hero
- Cursor personalizado
- Modal para leitura de artigos
- Totalmente responsivo (mobile, tablet, desktop)
- Smooth scroll com Lenis
